# Malaysia VFR Data for Foreflight
## Introduction
This project is intended to prepare Malaysia VFR data for ForeFlight. 

## Available Content
VFR waypoints data for importing as Custom Waypoints. 

Due to ForeFlight constraints, we cannot specify waypoint style (icon and icon color). If you don't like the default display, you can specify it yourself. But you will have to do it one waypoint at a time. 

## Future Content Ideas
Some ideas for Content Pack:

1. Waypoint photos - Helpful to identify the waypoints visually. Crowdsourcing required! Happy to accept pilot photos of waypoints. 
2. VFR lane overlays - Initial assessment is that the diagrams published in the WM-ENR are not accurate enough to be georeferenced. Content Pack line drawings are unfortunately not labelled. 

## Source of Data
User waypoints created from coordinates listed in WM-ENR-3.5, CAAM AIP published on 05 Nov 2020 (latest as of 29 Sep 2026).
